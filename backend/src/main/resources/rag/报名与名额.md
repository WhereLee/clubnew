# 纳新与活动报名规则

## 报名方式

- 社长发布的纳新或活动，会在「纳新广场」或「活动」页面展示。
- 报名前请确认活动时间、地点与名额要求。
- 名额有限时先到先得，报名成功以系统记录为准。

## 名额机制

- 每个纳新/活动有固定名额上限（quota），报名人数达到上限后不可再报名。
- 已取消的报名会立即释放名额，其他同学可继续报名。
- 系统采用三层防线防止超卖：Redis 预扣库存、数据库原子更新、唯一约束兜底。

## 取消报名

- 在报名截止时间前，可在「我的报名」中取消报名。
- 取消后名额自动回补。

## 纳新录取

- 纳新报名后进入面试/筛选环节，社长可标记「录取」或「落选」。
- 录取后一般会转入正式入社流程（以社团通知为准）。
