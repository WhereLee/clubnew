# 入社流程

## 如何加入社团

1. 登录用户端后，进入「社团广场」，浏览或搜索感兴趣的社团。
2. 点击社团卡片进入社团详情页，点击「申请入社」按钮。
3. 填写入社申请（可附简短自我介绍或申请理由），提交后状态变为「待审批」。
4. 社长或副社长在管理端审批：通过后你成为正式成员，拒绝后申请关闭。

## 审批时间

- 入社申请由该社团的社长或副社长审批，一般在 3 个工作日内处理。
- 审批结果可在「我的社团」页面查看。

## 退出社团

- 正式成员可在社团详情页申请退出社团。
- 退出后不再参与该社团的活动与纳新报名（历史记录保留）。

## 注意

- 同一时间只能申请一个社团，且不能重复申请同一社团。
- 被拒绝后可再次申请，但建议先了解拒绝原因。
