# 经费申请流程

## 申请条件

- 仅社团成员（社长/副社长）可为社团发起经费申请。
- 申请需填写：经费标题、金额、用途说明（类型：收入/支出）。

## 审批流程

1. 社长在社团管理页提交经费申请。
2. 系统管理员在管理端「经费审批」中审核。
3. 审批通过后自动生成经费流水记录；驳回需注明原因。

## 经费流水

- 每笔收支都会记录流水，包含金额、类型与审批后的余额。
- 余额 = 收入累计 − 支出累计，逐笔可追溯。
- 金额必须大于 0，系统在应用层与数据库层双重校验。

## 常见问题

- 问：经费申请被驳回可以重新申请吗？
  答：可以，修改后重新提交即可。
- 问：谁能看到经费流水？
  答：社团内成员可查看本社团流水，管理员可查看全部。
