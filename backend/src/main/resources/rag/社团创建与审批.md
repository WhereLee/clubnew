# 社团创建与审批

## 创建条件

- 登录用户端，进入「申请创建社团」页面。
- 填写社团名称、简介、分类（学术科技/文化艺术/体育运动/志愿公益）与成立申请说明。
- 社团名称与编号在平台内唯一，重复会被拒绝。

## 审批流程

1. 提交后社团状态为「待审批」。
2. 系统管理员在管理端「社团审批」审核：通过后社团成立，创建人自动成为社长；驳回需注明原因。
3. 审批通过后，社团进入「正常运营」状态，可发布纳新、活动与公告。

## 社团状态

- 正常运营：可开展全部业务。
- 已暂停：管理员暂停后社团功能受限，可恢复。
- 已注销：社团生命周期结束，不可再开展业务。

## 社长换届

- 社长可将社长职务移交给本社团其他正式成员（换届）。
- 换届采用分布式锁保证同一社团同一时刻只有一个换届操作成功。
