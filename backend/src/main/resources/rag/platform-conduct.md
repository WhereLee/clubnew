# 平台行为规范

## 内容发布规范

- 公告、动态、评论需文明友善，禁止发布违法、辱骂、广告内容。
- 动态与评论支持点赞互动，点赞/评论计数实时更新。

## 账号与安全

- 登录采用 access token（30 分钟）+ refresh token（7 天）双令牌机制。
- 长时间未操作需要重新登录；异常登录（refresh token 被他人复用）会触发全设备会话吊销。
- 请勿将账号借给他人使用。

## 排行榜规则

- 社团活跃度榜与动态热度榜基于互动行为加分：发布动态、评论、点赞、报名活动、纳新报名、活动签到都会为社团加分。
- 加分通过事件管道异步处理，实时性与最终一致性兼顾。

## 数据权限说明

- 学生只能看到与自己相关的数据；社长/副社长可查看本社团运营数据；管理员可查看全平台数据。
- 系统按角色配置的数据范围自动过滤查询结果。
